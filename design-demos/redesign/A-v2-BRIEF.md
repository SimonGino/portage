# A-v2 · Grok 港改成网关工作台

PO 裁：采用 A 的**视觉**，不要 A 的**聊天交互**。这是 AI 模型网关管理端，功能必须覆盖现有生产页，一件不能少。

旧文件 `A-grok-harbor.html` 只作色板/字体参考，不要复用它的胶囊对话、底栏输入槽、右对齐提问气泡。

## 视觉（从 A 原样拿）

- 左栏 248px，纸灰底 `#f3f3f1`，主画布白、大圆角 20
- 导航选中：浅底大圆角药丸，不用下划线、不用蓝
- 字体：Outfit 标题，IBM Plex Sans 正文，IBM Plex Mono 标识符
- 几乎无边框，分组靠间距和一层 `--sunken`
- 主按钮实心黑胶囊；次按钮幽灵
- 账号钉左栏底：改密码 / 退出
- 船体标记 path：`M3,6 L21,6 L17,13 L7,13 Z M0,17 L9,17 L9,21 L0,21 Z M15,17 L24,17 L24,21 L15,21 Z`
- 反 slop：无紫渐变、无 emoji 图标、无卡片左边彩条、无 Inter、无霓虹

## 交互（网关，不是聊天）

- 五项导航：模型 · API Key · 调用记录 · 接入点 · 排行。无概览。
- 左栏中段：只在「模型」页放**渠道列表 + 搜索 + 新建渠道**。其它页不要硬塞「会话式」次级列表。
- 主区是工作台：标题（动词）+ 主按钮 + **表格/清单/表单**。
- 禁止：右对齐胶囊当限定名、把探测结果画成助手回复、底部一条像 Ask anything 的状态槽、气泡对话节奏。
- 弹层：获取模型 / 新建编辑 key / 接入点 / 改密码 / 调用详情 —— 居中或右侧工作表，圆角白底，不是聊天气泡。

## 模型页（默认落地，功能必须齐）

左栏渠道（anthropic / bailian / openai 停用）。主区主语永远是**这个渠道的纳管模型列表**。

抬头：
- 渠道名 + 启停开关（立刻生效，不是表单里的复选框）
- 主按钮「获取模型列表」
- 文字按钮「上游设置」「上游凭证」——点开后在**模型列表上方**展开一块 sunken 井，再点收起。默认收起，列表是第一眼。

模型列表每行：
- 裸模型名（大、等宽）
- 副行：限定名 `渠道名/模型名`，可复制（停用的不给复制）
- 协议子集（多协议渠道或存量有子集时显示；单协议可只写继承）
- 启停、删除（删除要二次确认）

获取模型列表 = 弹层：搜索、显示已纳管、分组勾选、全选只作用于当前可见、确认纳管。样例里给几个未纳管名。

上游设置井（现网 ChannelForm 全套）：
- 渠道名（不能含 `/`）
- 支持协议：Anthropic / OpenAI / OpenAI-Responses（Gemini 置灰「暂未支持」）
- Base URL + **逐协议拼好的完整地址预览**（前缀脱敏，`****`）
- 并发上限（空=不限）
- 勾了 Responses 才出现：Codex 压缩 支持/不支持
- 保存（脏了才可点）、已保存回执
- 删除渠道（二次确认，写「该渠道被 N 个接入点引用」）
- 新建渠道时主区整页就是这张表 + 一份凭证输入，没有模型列表

上游凭证井（现网凭证池全套）：
- 说明：跟 API Key 是两回事
- 每条：名字（ghost 输入）、值默认掩码、显示、复制、启停、删除
- 已摘的标「已摘 · 401」+ 时刻，只能人工恢复（启）
- ≥2 把（含停用）才显示选取模式：轮询 / 随机
- 段标题旁「检测」：子路径层按凭证分行结论（状态 + 一句固定词表，不带上游原文）
- 模型矩阵贴在凭证井底部或模型列表顶：通 / 不通 / 说不清，有文字不只靠色
- 添加凭证：名 + 值 + 显示 + 添加

## API Key 页

表：名称、API Key（掩码/显示/复制；空串写「原值没存过，只能删了重建」）、可访问模型（`*`=不限）、创建时间、启停、编辑、删除。

新建/编辑弹层：名称、白名单（不限 或 多选：接入点名 + 限定名）、保存。新建成功再弹一次「新 API Key 已生成」+ 全串 + 复制（不再写「关掉就再也看不到」）。

## 调用记录页

定高视口表，列与现网一致：

时间 · API Key · 模型（主=请求名，副=渠道/上游）· 端点（入站一行、上游一行）· 类型（流式/同步/—）· 上游凭证 · 状态（码 + 错误词 + 重试 + 详情）· 耗时（总 + 首字）· in / out（思考 token 有数才露一行「思考 N」；缓存读写非零才露）

筛选：模型下拉（全部模型）、只看失败、刷新。
翻页：右下页码，可跳。
详情：有 request-id 或 status≥400 才出按钮。框内：模型、端点、状态、上游 request-id（可复制，空为 —）。上游原文**只在失败行**。

## 接入点页

表：接入点名（可复制）、候选（渠道 / 模型 + 权重）、状态、编辑、删除。
空态：没渠道时写「先去模型页建上游并纳管」；有渠道没接入点时写「不必建，客户端可直接填限定名」。
新建/编辑弹层：对外名、候选（按渠道分组的纳管模型）、权重、启停。

## 排行页

维度：按模型 / 按 API Key / 按上游凭证。
窗口：1 / 7 / 30 天。
一个合计（占比分母）。名次列表：名次、名字、token、占比。不要热门榜、厂商份额、环比、费用。
