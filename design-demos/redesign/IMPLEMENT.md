## 必须改的行为

1. **壳**：顶栏改 248px 左栏。品牌 + 五项导航（浅底药丸选中）+ 账号（改密码/退出）钉底。主画布白、大圆角 20，纸灰底 `#f3f3f1`。
2. **导航五项**（顺序）：模型 · API Key · 调用记录 · 接入点 · 排行。**去掉概览**。`/overview` 与 `/usage` 重定向到 `/rankings`。默认落地仍是渠道/模型页。
3. **模型页 = 原渠道页**。路由保持 `/channels`、`/channels/:id`（少改测试/书签）。导航文案写「模型」。
4. **渠道列表进左栏中段**（只在模型页出现）。用 portal 或 `RailMid` 插到 `.rail-mid`，不要在主画布里再做一列 master。搜索 + 列表 + 新建渠道。缺凭证/无协议/停用标记保留。
5. **模型是主语**：`ChannelDetail` 默认第一眼是纳管模型列表。「上游设置」「上游凭证」是抬头上的文字按钮，点开在**列表上方**展开 sunken 井，默认收起。探测按钮仍在凭证井标题旁。获取模型列表是主按钮。启停开关在渠道名旁立刻生效。删除渠道二次确认保留。
6. **ChannelForm / CredentialSection / ModelPicker / 探测矩阵** 逻辑不动，只换容器和样式。新建渠道时主区整页是表单（没有模型列表）。
7. **其它四页**：换 A 的页头（大标题 + 主按钮/工具条），表格/表单逻辑不动。调用记录仍是定高九列表 + 筛选翻页 + 详情。排行形态不动。
8. **登录页**跟壳同一套色和圆角。
9. **暗色**：`prefers-color-scheme: dark` 必须还在，给 A 的 token 配一套暗色，不要删。
10. **字体**：`web/index.html` 加 Outfit + IBM Plex Sans/Mono（Google Fonts）。标识符继续走等宽。
11. **文档**：`docs/口径层设计.md` 加 v0.75（导航五项、去掉概览、侧栏改做、模型页主从：左栏渠道 / 右栏模型主语 + 设置凭证井）。`DESIGN.md` 加 v0.23：推翻 v0.5/v0.17「侧栏不做」；壳改 A；内容区不再顶栏+居中 1520 画布。修改人一律 `jinpenga`。展开层 `docs/MVP设计草案.md` 只补一句对应版本头，不回灌实现细节到口径。
